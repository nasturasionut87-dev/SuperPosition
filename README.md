# SUPERPOSITION — $SUPER

Static memecoin landing page for GitHub Pages.

## GitHub Pages

1. Upload `index.html` to a public GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

The site will be published at your GitHub Pages URL.

## Before launch

Replace the placeholder contract address and community links with the official $SUPER links.
